ПРОЗРАЧНО И ПО ДЕЛУ

Что происходит с данными

Настройки, календарь и зафиксированный план хранятся в localStorage этого браузера. Краткосрочная авторизация хранится в sessionStorage вкладки в зашифрованном виде, до одного часа. Обычный токен GitHub сервер в браузер не передаёт.

Сервер расшифровывает авторизацию и обрабатывает план в оперативной памяти на время запроса. В приложении нет базы данных, дисковых Git-репозиториев, аналитики и записи содержимого запросов в логи.

GitHub хранит авторизацию и опубликованную историю. GitHub Pages и провайдер API обрабатывают технические метаданные по своим политикам. Провайдер API ведёт журналы с IP-адресом и URL запроса; на шаге входа URL содержит одноразовый код OAuth. Срок хранения этих журналов определяется провайдером. Отсутствие любых записей у сторонних провайдеров не обещается.

«Очистить браузер» удаляет данные этого приложения на устройстве. Это не отзывает разрешения GitHub. Для этого используй «Отозвать доступ GitHub» или настройки GitHub; удаление установки приложения — отдельное действие.
