# Данные и границы хранения

Версия политики: 2026-11-10.

| Данные | Где и сколько |
|---|---|
| Настройки, календарь, план, квитанция | localStorage браузера до очистки пользователем |
| Зашифрованная авторизация | sessionStorage вкладки; сервер принимает envelope не более часа |
| OAuth state, PKCE verifier, nonce | зашифрованная HttpOnly cookie API до 10 минут; удаляется после входа |
| Provider access token, тело плана, Git pack | оперативная память сервера на время запроса |
| Refresh token | не сохраняется и не используется |
| Опубликованная история | выбранный пользователем приватный репозиторий GitHub |
| Авторизации и установки | в аккаунте GitHub до отзыва/удаления пользователем |
| Client secret и ключ шифрования сервиса | runtime secret store хостинга; это секреты самого сервиса |

В приложении нет БД, KV, R2, D1, дисковых Git-репозиториев, аналитики, фоновых задач, дампов запросов и записи пользовательских данных в логи. Сессии и планы не кэшируются в глобальном состоянии Worker.

GitHub Pages обслуживает статику. Сервер OAuth возвращает авторизацию в URL fragment, который не передаётся в HTTP-запросах Pages; маленький локальный скрипт удаляет fragment до загрузки остальных скриптов. Nonce привязывает handoff к вкладке, начавшей вход. Секретный токен GitHub не передаётся JavaScript интерфейса в открытом виде, но зашифрованная сессия является bearer credential: не копируйте её и защищайте браузер.

Нельзя обещать отсутствие любых записей у сторонних провайдеров. GitHub и хостинг могут обрабатывать IP-адрес, время запроса, статус, User-Agent и другую техническую информацию по своим политикам. В частности, OAuth callback содержит краткоживущий код в query string. Перед публичным запуском оператор должен убедиться, что reverse proxy, edge/access logs, APM, exception tracking и request inspection не сохраняют query string, Authorization, Cookie, response Location, тела или содержимое запросов. `wrangler.json` отключает Worker observability приложения; это не является доказательством отключения всех журналов провайдера.

«Очистить браузер» удаляет ключи `af.*` приложения. Она не удаляет репозитории и не отзывает GitHub App. «Отозвать доступ GitHub» вызывает официальный endpoint отзыва grant; установка приложения остаётся отдельным объектом. Удалить её можно на https://github.com/settings/installations . Если срок локальной сессии уже истёк, используйте https://github.com/settings/apps/authorizations .
